Hindi, and measure real enquiries. No ranking or citation is promised. Branch: `geo-foundations` (built on `product-reviews-rail-faq`). Nothing is deployed.

publishing prices.

## 7. Addendum, 12 Oct 2026: owner decisions applied

Full per-fact table: [fact-ledger.md](fact-ledger.md).

**Manufacturer claim.** Kept, limited to what was confirmed: "We manufacture barbed wire, chain link fencing and wire
mesh. The rest of our range is stocked and supplied." (Hindi equivalent in `content/hi/site.ts`.) The old wording named
"Welded Wire Mesh & SS Wire Mesh" and had no limit; the new text names only the three confirmed products. `llms.txt` says
the same.

**Reach.** The exact sentence "Orders accepted across India; delivery arrangements confirmed with each quotation." now
appears, in English and Hindi, in: site config (`orderReach`), Organization/HardwareStore `areaServed` (Country: India,
the three states and the nearby-town list are gone), home and category FAQs, product service-area text and delivery FAQs
(`content/productSeoContent.ts`), the Indore landing pages, the services page, five guides, and `llms.txt`.
Local towns (Dewas, Ujjain, Mhow, Pithampur) are still named as nearby places the shop serves; no copy promises free or
universal delivery. `tests/geo.test.mjs` fails if the old "delivery depends on..." wording or any "free delivery" returns.

**Crawlers.** `ALLOW_TRAINING_CRAWLERS = false`. Published `robots.txt` (checked from a running build):

```
User-Agent: *
Allow: /
Disallow: /api/
Disallow: /contact/success
Disallow: /hi/contact/success

User-Agent: GPTBot
User-Agent: ClaudeBot
User-Agent: Google-Extended
User-Agent: Applebot-Extended
User-Agent: CCBot
User-Agent: meta-externalagent
User-Agent: Bytespider
Disallow: /
```

Search and retrieval tokens (Googlebot, Bingbot, OAI-SearchBot, ChatGPT-User, Claude-SearchBot, Claude-User,
PerplexityBot, Perplexity-User, Applebot, meta-webindexer) have no rule of their own, so they follow the `*` group and stay
allowed. Where training cannot be separated from search or from something else the shop wants, see the table in the
fact ledger: **Google** (Google-Extended also covers Gemini grounding; AI features inside Search ride on Googlebot),
**Microsoft/Bing** (no robots.txt control; meta tags only, not verified against Microsoft's own page and not applied),
and **Amazon** (one token; noarchive meta tag is its training control, not applied). `robots.txt` is a request, not
enforcement, and it does not remove anything already collected.

**Opening hours.** Unchanged, still 9 am to 8 pm on the site against 10 am to 8 pm on the Google listing. Both still
appear side by side in Google results. Open.

**Apex domain, rechecked 12 Oct 2026: problem persists.**

| Check | Result |
|---|---|
| `hmibrahim.net` A, AAAA, CNAME | none. Query returns NOERROR with an empty answer from Google, Cloudflare and Quad9 resolvers |
| Name servers | `ns27.domaincontrol.com`, `ns28.domaincontrol.com` (GoDaddy; registrar is GoDaddy) |
| `www.hmibrahim.net` | CNAME to `add7eb51053e2b08.vercel-dns-017.com`, resolves, serves the site |
| `https://hmibrahim.net/`, `http://hmibrahim.net/` | cannot connect (no address to connect to) |
| Vercel domain config for `hmibrahim.net` | `misconfigured: true`, no A or CNAME values found, recommended A `76.76.21.21` |

Cause: the DNS zone at GoDaddy has a record for `www` but none for the bare domain, so the apex has nothing to connect to.
The Vercel account connected to this session does not contain the HM project (it lists two other projects), so whether
the apex is already attached to the project in Vercel could not be read.

**Exact fix (needs GoDaddy and Vercel access; not done):**

1. GoDaddy, DNS for `hmibrahim.net`, add one record: Type `A`, Name `@`, Value `76.76.21.21`, TTL 1 hour. Leave the existing `www` CNAME alone. (Vercel's own configuration check recommends this value; if the project's Domains page shows a different value, use that one.)
2. Vercel, project for hmibrahim.net, Settings, Domains: add `hmibrahim.net` and set it to redirect (308) to `www.hmibrahim.net`, so there is still one canonical host. Vercel then issues the certificate.
3. Verify: `dig +short A hmibrahim.net` returns the address, and `curl -sI https://hmibrahim.net/` returns `308` with `location: https://www.hmibrahim.net/`.

Until then, the Google listing's website link and the Instagram bio link, both written as `hmibrahim.net`, cannot load.
